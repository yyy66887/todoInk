- 总体规范沿用 [前端设计方案](../../design/TodoInk_前端设计方案.md) 的纸白 / 墨黑 / 紫色、Compose 组件和无障碍约定；业务以 [AI 模块](README.md) 为准。

## 1. 导航与入口

拟将底部导航扩展为 **待办 / 待确认 / 消息盒子 / AI / 设置**，与 [产品 MVP](../../harness/MVP_PRODUCT_PLAN.md) 一致。消息盒子由 MB-001 / MB-002 实现按 App 分抽屉和跳转。AI 管理消息处理，设置保留采集、授权状态、数据保留与关于；避免两处维护相互冲突的模型开关。AI 子页隐藏底栏并保留返回，主页面保留底栏。

```text
AI（P10）
  ├─ 本地模型（P11）：下载 / 导入 → 校验 → 设备自检 → 就绪
  ├─ 云端服务（P12）：地址 / Key / 模型 → 合成测试 → 保存
  ├─ 处理来源（P13）：本地处理来源 / 云端允许发送来源
  └─ 处理记录（P14）：状态筛选 → 原通知 / 候选 / 错误与重试
```

## 2. P10：AI 首页

从上到下排布：标题“AI”与副标题“把消息整理成待办建议”；处理模式单选；当前引擎卡；来源摘要；“自动生成待确认项”开关；处理统计与最近记录。初始模式为关闭、无伪造统计，选择引擎但未就绪时开关不可启用，旁边给出具体下一步。

| 模式 | 当前引擎卡 | 主操作 / 边界文案 |
| --- | --- | --- |
| 关闭 | 尚未启用消息处理 | “选择处理方式”；“通知仍会采集和保存” |
| 本地 AI | 实际模型名称、就绪 / 未下载 / 加载失败 / 资源暂停 | “管理本地模型”；“消息在本机处理” |
| 云端 AI | 用户命名的服务、目标域名、Model ID、连接状态 | “配置云端服务”；“所选来源的消息将发送至此服务” |

模式选择用于准备配置，自动处理开关才开始处理；持久化配置用 mode 与 enabled 表达，enabled=false 对调度器等效 OFF。切换模式先关闭自动处理，保留旧候选；新模式就绪后由用户开启，说明只处理后续新消息。不要让用户误以为保存 Key 或一次测试已经开始持续发送。

统计显示今天处理数、生成建议数、需判断数和失败数；“处理数”与“候选数”分开，一条消息可能包含多项行动。若某模式尚未随版本交付，明确“暂不可用”，不能伪造“已连接”。

## 3. P11：本地模型

- 显示经验证的兼容型号 / 内存建议、模型版本与量化、文件大小、所需磁盘空间、许可 / 来源链接；未实测手机显示“兼容性待测试”。
- 模型入口为受控下载源或用户选择文件。导入不等于兼容：检查格式、校验摘要、完整性、运行时和 chat template 版本；失败给出可行动原因。
- 状态覆盖未安装、下载 / 导入中、校验中、已安装未加载、加载中、就绪、设备不支持、加载失败、资源暂停。下载中提供取消 / 重试，不显示虚构百分比。
- “运行设备测试”只用内置合成通知，显示通过 / 失败、实际耗时和资源测量；不在 UI 把模型参数量当成所需内存。
- 先保存和完成设备测试，再回首页开启自动处理。正在使用的模型卸载前提示会停止处理，先取消作业并释放运行时，再删除文件；已有任务保留。
- 文案：“模型就绪后可离线处理。模型不可用时会暂停，不会自动把消息发到云端。”

## 4. P12：云端服务

| 字段 / 操作 | 交互要求 |
| --- | --- |
| 服务名称 | 用户便于识别的名称，非供应商认证标识 |
| 接口协议 | 首版固定“兼容 Chat Completions”；以后按真实适配器扩展 |
| API Base URL | 必填 HTTPS；显示解析后的目标域名和请求端点供核对 |
| API Key | 必填、默认掩码、允许替换 / 删除；不回显完整已保存 Key |
| Model ID | 必填手动输入；不依赖服务必须支持模型列表 |
| 高级限制 | 每日请求上限、超时、输出上限；显示作用与当前值 |
| 测试配置 | 按钮明确“发送内置示例测试，可能产生少量费用”；不读取通知样本 |
| 保存配置 | 存为待启用配置；改 URL / Key / 模型后重新测试，旧测试结果失效 |

测试使用例如“请明天十五点前提交周报”的合成文本，依次报告网络 / 鉴权、模型响应、提取结构校验；HTTP 200 但输出无法解析时显示“服务可连接，提取未通过”。不以普通 GET 成功冒充可用模型。

首次开启云端自动处理时展示目标域名、所选来源、发送字段摘要，主按钮“允许并开启”；来源默认全不选。此操作仅是 App 用户启用产品功能的流程，不代表开发过程中可以发送现有私人通知。更换目标域名清空云端来源授权并再次选择，防止把原授权迁移给新服务。

Key 删除或无法解密时立即停用云端模式，提示重新配置。额度 / 用量缺失显示未知；供应商返回的错误正文不原样展示，以免泄露 Key、请求或其他内容。

## 5. P13：处理来源

仅列采集页已允许的来源。提供“允许 AI 处理”列表，默认不选；云端另列“允许发送至当前服务”，也默认不选。取消采集来源会立即从可处理和可发送范围中移除；重新选择采集来源不会自动恢复云端允许发送。

展示作用范围：“仅处理开启后收到的新消息；不补发历史”。本地模式不出现含糊的“云端增强”开关。保存成功作为变更生效的边界，旧请求若已发出则提示无法撤回，迟到结果仍须拒绝。

## 6. P14：处理记录

筛选：全部 / 待处理 / 已生成建议 / 非任务 / 需判断 / 失败。暂停、取消与过期在条目中单独标识。卡片显示来源、时间、状态和本地 / 云端标记，默认不露完整正文或 API 地址。

| 记录 | 操作 |
| --- | --- |
| 已生成建议 | 打开候选；候选已确认时打开正式待办 |
| 非任务 | 查看仍在保留期内的原通知，不显示“重新确认” |
| 需判断 | 看原因与原通知；首版不提供尚未实现的手工建任务按钮 |
| 失败 / 暂停 | 显示错误分类与可执行操作：配置服务、下载模型、稍后重试等 |
| 输入已过期 / 来源关闭 / 配置已变化 | 明确不可重试的原因，不跨新配置补发旧消息 |

同配置下重试可能重复产生云端费用时，在按钮旁说明；禁止连续点击产生并发重复请求。详情展示原文证据和可理解的原因，不展示模型内部思考过程。原文过期时显示“原通知已清理”。

## 7. 其他页面联动与验收

- 待确认卡片增加“本地 AI”或“云端 AI”的次级标签，详情显示服务 / 模型来源；“确认加入待办”的含义不变。
- 通知详情增加处理状态与 AI 记录入口；AI 暂停不覆盖通知访问权限状态。
- 设置页原“本地候选识别”设计入口迁移至 AI，不提供第二个开关。有关隐私的文案随实际模式变化；云端启用时不能仍写“所有消息仅在本机处理”。
- 五入口在窄屏、大字体、深色、TalkBack 下验收；失败和暂停不能只用颜色区分，配置与测试不得阻塞页面返回。
- 现有 [四入口原型](../../design/todoink-preview.html) 是 v0.1 参考，不包含本轮 AI 页面。实施批次 AI-004 才更新 / 实现这些交互，不能以旧原型走查代替。
