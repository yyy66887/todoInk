1. 从当前代码运行 Static / Verify / Device，核对报告时间与基线；重复利用 Phase 1 回归，确保新增提取没有破坏采集。
2. 执行方案的 P2-V01–P2-V12，覆盖重放、状态竞争、来源关闭、取消、进程恢复、迁移与清理。

5. 联合 AI-005 验收 AI-V01–V10；分别记录本地模型 / 运行时 / 量化与云端服务 / 模型 / 模板版本。交付 debug APK、基线 / SHA-256、报告、设备与来源版本、已知限制。不自动开始后续 AI 优化或 BLE 阶段。
