# TD-000：核对输入就绪与建立标注样本

- 状态：DRAFT；执行范围见 [Phase 2 方案](../MVP_PHASE2_PLAN.md)，尚未批准实施。
- 里程碑：P2-M0；依赖：无前置 TD 任务；真实样本依赖来源和设备条件。

## 目标与边界

明确 Phase 2 实际能消费什么，建立有人工复核标签的样本。复用 NI-000，不重建测试底座；Phase 1 缺陷继续归属原 NI 任务。

## 交付

1. 核对 NI-001 / NI-002 / NI-003 的来源、持久化和去重契约，以及 NI-004–NI-007 的相关证据；列出可开发、可集成、仍待验收的内容。
2. 固定消息输入：正文、可确认的发送人 / 会话、消息与观察时间、来源字段、隐藏 / summary 信息、解析版本；缺失字段明确标为未知。
3. 整理正例、负例、不确定例，包含“请你做”和“我来做”、否定、群聊、重复消息、模糊时间与多行动项。
4. 开发样本与独立验收样本分开，人工复核标签和证据；原 60 条用于早期冒烟，[AI 双模式评测](../../product/AI/IMPLEMENTATION.md) 建议独立 200 条（80 行动 / 80 非行动 / 40 不确定）。真实样本先脱敏，标记来源结构，不保存私人数据库。
5. 固定支持语法、时间精度规则和评测口径；如需要数值门槛，在开发前记录理由与审核结果。
